一、计算机科学基础

1.1 数制转换

知识点详解

常用进制

  • 二进制（Binary）：基数为2，数字0-1
  • 八进制（Octal）：基数为8，数字0-7
  • 十进制（Decimal）：基数为10，数字0-9
  • 十六进制（Hexadecimal）：基数为16，数字0-9，A-F

转换方法

  1. 其他进制 → 十进制：按权展开求和

  2. 十进制 → 其他进制

    • 整数部分：除基取余，逆序排列
    • 小数部分：乘基取整，顺序排列

  3. 二进制 ↔ 八进制：3位一组

  4. 二进制 ↔ 十六进制：4位一组

易错点

  1. 小数部分转换时，某些十进制小数无法精确表示为二进制
  2. 八进制转二进制时，每组必须是3位，不足补0
  3. 十六进制中A-F大小写均可，但A=10，不是11

练习题

题目：将十进制数 25.625 转换为二进制数。

答案：

  • 整数部分：25 ÷ 2 = 12…1 → 12 ÷ 2 = 6…0 → 6 ÷ 2 = 3…0 → 3 ÷ 2 = 1…1 → 1 ÷ 2 = 0…1
    • 逆序：11001
  • 小数部分：0.625 × 2 = 1.25 → 取1，余0.25
    • 0.25 × 2 = 0.5 → 取0
    • 0.5 × 2 = 1.0 → 取1
    • 顺序：101
  • 结果：11001.101

1.2 数据表示

知识点详解

原码、反码、补码

表示法 正数 负数
原码 符号位0，数值位不变 符号位1，数值位不变
反码 与原码相同 符号位1，数值位取反
补码 与原码相同 反码末位加1

特殊数值

  • [+0]原 = 00000000，[-0]原 = 10000000
  • [+0]补 = [-0]补 = 00000000
  • [-128]补 = 10000000（8位补码最小值）

浮点数表示

浮点数规格化

  • 尾数最高位必须为有效值
  • 原码规格化：尾数最高数值位为1
  • 补码规格化：尾数符号位与最高数值位不同

易错点

  1. 补码的加减运算不需要判断符号，直接运算即可
  2. 补码表示范围比原码多一个负数（-2^n）
  3. 浮点数运算可能产生精度损失和溢出

练习题

题目：用8位补码表示 -35，并计算 35 + (-35) 的结果。

答案：

  • 35的二进制：00100011
  • -35的原码：10100011
  • -35的反码：11011100
  • -35的补码：11011101
  • 35 + (-35)：00100011 + 11011101 = 100000000（溢出舍去）= 00000000

1.3 计算机体系结构

知识点详解

冯·诺依曼体系结构

  • 五大部件：运算器、控制器、存储器、输入设备、输出设备
  • 存储程序原理
  • 指令由操作码和地址码组成

Flynn分类法

类型 指令流 数据流 代表
SISD 单 单 单处理器
SIMD 单 多 向量处理器、GPU
MISD 多 单 理论模型
MIMD 多 多 多核处理器、集群

流水线技术

  • 指令流水线：取指 → 译码 → 执行 → 访存 → 写回
  • 流水线周期 = 最长段的时间
  • 流水线执行时间 = (n + k - 1) × 周期时间
    • n：指令数
    • k：流水线级数

易错点

  1. 流水线的加速比 = 非流水线时间 / 流水线时间
  2. 流水线冲突：结构冲突、数据冲突、控制冲突
  3. 超标量：多个流水线并行执行

练习题

题目：某指令流水线分为4级，各段执行时间分别为2ns、3ns、2ns、4ns。执行10条指令需要多长时间？

答案：

  • 流水线周期 = max(2, 3, 2, 4) = 4ns
  • 执行时间 = (10 + 4 - 1) × 4 = 52ns

1.4 存储系统

知识点详解

存储器层次结构

Cache映射方式

映射方式 特点 地址结构
直接映射 每个块只能映射到固定位置 主存字块标记 + Cache字块地址 + 字块内地址
全相联映射 任何块可映射到任何位置 主存字块标记 + 字块内地址
组相联映射 映射到固定组内的任意行 主存字块标记 + 组地址 + 字块内地址

Cache命中率与平均访问时间

  • 命中率 h = 命中次数 / 总访问次数
  • 平均访问时间 = h × tc + (1-h) × tm
    • tc：Cache访问时间
    • tm：主存访问时间

易错点

  1. Cache大小计算需考虑块大小和映射方式
  2. 虚拟存储器由操作系统实现，对用户透明
  3. 局部性原理：时间局部性、空间局部性

练习题

题目：某Cache容量为16KB，块大小为32B，采用4路组相联映射。主存地址为32位，求主存字块标记、组地址、字块内地址的位数。

答案：

  • 字块内地址：log₂(32) = 5位
  • Cache块数：16KB / 32B = 512块
  • 组数：512 / 4 = 128组
  • 组地址：log₂(128) = 7位
  • 主存字块标记：32 - 7 - 5 = 20位

2.1 进程管理

知识点详解

进程状态转换

进程同步与互斥

  • 临界资源：一次仅允许一个进程访问的资源
  • 临界区：访问临界资源的代码段
  • 信号量：P操作（申请）、V操作（释放）

PV操作应用

死锁

  • 产生条件：互斥、请求保持、不可剥夺、循环等待
  • 预防：破坏四个必要条件之一
  • 避免：银行家算法

易错点

  1. P操作可能阻塞进程，V操作可能唤醒进程
  2. 信号量初值由具体问题决定，不是固定值
  3. 死锁定理：资源分配图中存在环路不一定死锁

练习题

题目：某系统有5个进程，4类资源。当前资源分配情况如下表，判断系统是否处于安全状态。

进程 最大需求 已分配
P0 8 5 9 7 2 1 2 1
P1 4 3 2 1 1 0 1 0
P2 6 2 3 2 2 1 1 1
P3 5 3 2 2 1 0 1 1
P4 3 4 2 3 0 1 0 2

系统可用资源：(1 2 1 1)

答案：
使用银行家算法：

  1. 计算Need矩阵（最大需求-已分配）
  2. 找Need ≤ Available的进程
  3. 执行后释放资源，更新Available
  4. 重复直到所有进程完成或无满足条件的进程

安全序列：P1 → P3 → P4 → P0 → P2 或 P1 → P4 → P3 → P2 → P0
系统处于安全状态。

2.2 进程调度算法

知识点详解

常用调度算法

算法 特点 适用场景
FCFS（先来先服务） 按到达顺序执行 批处理系统
SJF/SPF（短作业优先） 优先执行短作业 批处理系统
SRTN（最短剩余时间优先） 抢占式SJF 批处理系统
RR（时间片轮转） 公平分配CPU 分时系统
优先级调度 按优先级执行 实时系统
多级反馈队列 动态调整优先级 通用系统

评价指标

  • 周转时间 = 完成时间 - 到达时间
  • 带权周转时间 = 周转时间 / 服务时间
  • 平均周转时间 = Σ周转时间 / 进程数

易错点

  1. SJF是非抢占式的，SRTN是抢占式的
  2. 时间片轮转中时间片太大退化为FCFS
  3. 优先级调度可能导致饥饿现象

练习题

题目：有4个进程同时到达，执行时间分别为：P1=6，P2=3，P3=8，P4=4。采用SJF调度，计算平均周转时间。

答案：

  • 执行顺序：P2 → P4 → P1 → P3
  • P2：周转时间 = 3
  • P4：周转时间 = 3 + 4 = 7
  • P1：周转时间 = 7 + 6 = 13
  • P3：周转时间 = 13 + 8 = 21
  • 平均周转时间 = (3 + 7 + 13 + 21) / 4 = 11

2.3 存储管理

知识点详解

分区分配算法

  • 首次适应：从低地址开始找第一个满足的空闲区
  • 最佳适应：找最小的满足要求的空闲区
  • 最坏适应：找最大的空闲区

分页存储

  • 逻辑地址：页号 + 页内地址
  • 物理地址：页帧号 + 页内地址
  • 页表：页号到页帧号的映射
  • 地址转换：物理地址 = 页帧号 × 页大小 + 页内地址

分段存储

  • 逻辑地址：段号 + 段内地址
  • 段表：段号到段首地址和段长的映射
  • 优点：便于共享和保护

虚拟存储器

  • 局部性原理
  • 请求分页：缺页中断
  • 页面置换算法：
    • OPT（最优）：淘汰将来最久不使用的页面
    • FIFO：淘汰最早进入的页面
    • LRU：淘汰最近最久未使用的页面
    • CLOCK：时钟算法

易错点

  1. 页大小必须是2的幂次
  2. Belady异常：FIFO算法中，增加页帧数反而增加缺页率
  3. 分页对用户不可见，分段对用户可见

练习题

题目：某系统采用分页存储管理，页大小为4KB，逻辑地址32位。某进程页表如下，求逻辑地址0x12345678对应的物理地址。

页号 页帧号
0 5
1 9
2 3
… …

答案：

  • 页大小4KB = 2^12，页内地址12位
  • 逻辑地址0x12345678：
    • 页号：0x12345（高20位）
    • 页内地址：0x678（低12位）
  • 查页表，页号0x12345对应的页帧号（需查完整页表）
  • 假设页号=1，页帧号=9
  • 物理地址 = 9 × 4096 + 0x678 = 0x9000 + 0x678 = 0x9678

2.4 设备管理

知识点详解

I/O控制方式

  • 程序查询方式：CPU不断查询设备状态
  • 中断方式：设备完成后中断CPU
  • DMA方式：数据直接在内存和设备间传输
  • 通道方式：I/O处理器独立执行I/O操作

SPOOLing技术

  • 假脱机技术
  • 利用磁盘作为缓冲
  • 实现独占设备的共享

磁盘调度算法

算法 特点
FCFS 按请求顺序访问
SSTF 最短寻道时间优先
SCAN 电梯算法，来回扫描
C-SCAN 单向扫描，快速返回
LOOK 改进SCAN，到最远请求即返回

易错点

  1. DMA传输前和传输后仍需CPU干预
  2. 磁盘访问时间 = 寻道时间 + 旋转延迟 + 传输时间
  3. C-SCAN的返回过程不服务任何请求

练习题

题目：磁盘请求序列：98，183，37，122，14，124，65，67。磁头初始位置53，采用SCAN算法（向大磁道方向），求磁头移动总距离。

答案：

  • 当前方向向大磁道
  • 排序请求：14, 37, 65, 67, 98, 122, 124, 183
  • 扫描顺序：53 → 65 → 67 → 98 → 122 → 124 → 183 → 磁道末端 → 37 → 14
  • 假设磁道末端为200
  • 移动距离 = (65-53) + (67-65) + (98-67) + (122-98) + (124-122) + (183-124) + (200-183) + (200-37) + (37-14)
  • 或简化计算：= (200-53) + (200-14) = 333

5.3 范式理论

知识点详解

函数依赖

  • 完全函数依赖：Y完全依赖于X，不依赖于X的任何真子集
  • 部分函数依赖：Y依赖于X的真子集
  • 传递函数依赖：X→Y，Y→Z，则X→Z

范式

范式 条件 解决的问题
1NF 属性不可再分 消除重复组
2NF 满足1NF，消除部分函数依赖 消除部分依赖
3NF 满足2NF，消除传递函数依赖 消除传递依赖
BCNF 满足3NF，主属性不部分/传递依赖于码 消除主属性对码的部分/传递依赖

规范化过程

易错点

  1. 3NF允许主属性传递依赖于码，BCNF不允许
  2. 所有范式都首先要求满足1NF
  3. 规范化程度越高，查询效率可能降低

练习题

答案：

  • 候选码：A
  • 存在传递依赖：A→B→C→D→E
  • R属于2NF（无部分依赖，有传递依赖）

规范化到BCNF：

  • R1(A, B)：A→B，码A
  • R2(B, C)：B→C，码B
  • R3(C, D)：C→D，码C
  • R4(D, E)：D→E，码D

  • 例：192.168.1.0/24 表示前24位为网络位

易错点

  2. 子网掩码可以不是连续的1，但实际应用中都是连续的
  3. NAT用于私有地址和公有地址的转换

知识点详解

  • 过程：发送方用私钥对消息摘要加密

  • 格式：X.509标准
  • 内容：持有者信息、公钥、CA签名、有效期等

  1. 数字签名不能保证机密性，需要配合加密

  3. CRL和OCSP用于检查证书撤销状态

练习题

题目：解释数字签名的过程和作用。

答案：
签名过程：

  1. 发送方计算消息的哈希值（摘要）
  2. 用发送方的私钥加密哈希值，得到数字签名
  3. 将消息和签名一起发送

验证过程：

  1. 接收方用发送方的公钥解密签名，得到哈希值H1
  2. 接收方计算消息的哈希值H2
  3. 比较H1和H2，相同则验证通过

作用：

  • 身份认证：只有私钥持有者才能生成有效签名
  • 不可抵赖：发送方不能否认发送过消息
  • 完整性：消息被篡改后签名验证失败

结构 特点 应用

知识点详解

二叉树性质

类型 特点

附录A：常用公式汇总

进制转换

  • n位二进制最大值：2^n - 1
  • 二进制转十进制：Σ(bit × 2^position)

存储器

  • Cache平均访问时间：h × tc + (1-h) × tm
  • 虚拟地址位数：log₂(虚拟地址空间大小)

进程调度

  • 周转时间 = 完成时间 - 到达时间
  • 带权周转时间 = 周转时间 / 服务时间

数据结构

  • 完全二叉树结点i的父结点：⌊i/2⌋
  • 完全二叉树结点i的左孩子：2i
  • 完全二叉树结点i的右孩子：2i+1
  • 二叉树叶子结点数n0 = n2 + 1
  • n个结点的完全二叉树深度：⌊log₂n⌋ + 1

排序算法复杂度

  • 最好情况（已排序）：插入排序O(n)、冒泡排序O(n)
  • 最坏情况（逆序）：快速排序O(n²)
  • 平均O(nlogn)：快速、归并、堆排序
